## 🎯 Что внутри

Этот проект демонстрирует простую, но показательную ситуацию:

- 🧸 **2D-платформер** с управлением персонажем
- 🪙 **Сбор монеток** и начисление очков
- 📊 **UI-текст** с отображением текущего счёта

А главное — два подхода к архитектуре:

| `main` | `with-vcontainer` |
|--------|-------------------|
| Классический синглтон `ScoreManager` | Инверсия зависимостей через VContainer |
| Жёсткая связанность | Слабая связанность через интерфейс |
| Неявные зависимости | Явное внедрение через `[Inject]` |
| Сложно тестировать | Легко подменить реализацию |
